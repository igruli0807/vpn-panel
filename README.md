# vpn-panel

Лёгкая веб-панель для своих VPN-серверов на **AmneziaWG** и установщик **AmneziaWG 3.1** рядом с тем,
что уже стоит (в том числе рядом с контейнерами приложения Amnezia VPN).

- все клиенты со всех серверов в одном окне: кто в сети, когда подключался, откуда, сколько трафика;
- добавить / отключить / включить / переименовать / удалить клиента;
- раздача конфига: **QR прямо с экрана** или **ссылка со сроком** (одноразовая по умолчанию);
- «Перевести на AWG 3.1» — старому клиенту новый конфиг с тем же именем;
- тревога, если сервер не отвечает или VPN-интерфейс в контейнере не поднят;
- панель — один процесс Python из стандартной библиотеки (+ вложенный `segno` для QR), ~25 МБ памяти,
  без Docker, без базы данных-сервера, без CDN.

Поддерживаемые контейнеры: `awg3` (ставит этот пакет), `amnezia-awg2`, `amnezia-awg` (Legacy),
`amnezia-wireguard` (созданные приложением Amnezia). SSTP и VLESS — в планах, установщик уже
знает эти ключи (`--proto sstp|vless`) и честно отвечает, что их пока нет.

## Установка

Нужны Debian 12 / Ubuntu 22.04+, root, `python3` ≥ 3.9. Для VPN-сервера — Docker (поставится сам).

```bash
git clone https://github.com/igruli0807/vpn-panel /opt/vpn-panel && cd /opt/vpn-panel

# 1. VPN-сервер: AmneziaWG 3.1 в контейнере "awg3" (ключи, обфускация и порт — сами)
./install.sh server --proto awg3

# 2. Панель (на том же или на другом хосте); контейнеры этого хоста подключатся автоматически
./install.sh panel --id fin --title "Финляндия" --tz Europe/Helsinki
vpn-panel-passwd && systemctl start vpn-panel      # пароль администратора (≥ 10 символов)

# 3. Ещё один VPN-сервер в ту же панель (запускать на хосте панели)
./install.sh add-server --id usa --title "США" --host 203.0.113.10

# Что работает и чего не хватает
./doctor.sh
```

Панель откроется на `https://<IP>:2053`. Сертификат самоподписанный: браузер один раз предупредит.

Удалить AWG 3.1 с сервера: `./install.sh server --remove --proto awg3` (ключи остаются в `/opt/awg3`).

## Как устроено

```
 браузер ──HTTPS──▶ vpn-panel (python, пользователь vpnpanel)
                       │  sudo awgctl ...            (локальный сервер)
                       │  ssh awgctl ...             (удалённый: ключ с command=, from=, no-pty)
                       ▼
                    awgctl ──docker exec──▶ awg3 / amnezia-awg2 / amnezia-awg / amnezia-wireguard
```

- `server/awgctl` — единственная точка изменений на VPN-сервере. Правит конфиг атомарно (с копией
  предыдущих 20 версий в `/var/backups/awgctl`), применяет к живому интерфейсу без разрыва сессий,
  для контейнеров Amnezia обновляет `clientsTable`, чтобы приложение видело те же имена. Приватные
  и preshared-ключи наружу не отдаёт никогда. Отключённые клиенты лежат в `<conf>.disabled`.
- `images/awg3` — образ: amneziawg-go и amneziawg-tools 3.1 (userspace, ядро 6.7+ не нужно) и
  сторож: если интерфейс пропал — поднимает снова. Готовый образ: `ghcr.io/igruli0807/awg3`.
- `server/awg-guard.*` — тот же сторож для контейнеров приложения Amnezia: они умеют неделями
  висеть «Up» без VPN-интерфейса после перезагрузки.
- Имя контейнера `awg3`, а не `amnezia-*`: приложение Amnezia его не увидит и не перезапишет.
  Клиенты подключаются к нему импортом конфига/QR, а не через «управление сервером» в приложении.

## Безопасность

- Вход по одному паролю (scrypt); 5 ошибок за 15 минут — IP блокируется на час.
- Сессии в БД (хранится только хэш токена), cookie `Secure; HttpOnly; SameSite=Strict`, CSRF на всех
  изменениях, CSP `default-src 'self'`, без inline-скриптов и стилей.
- Ссылки для клиентов: 256 бит случайности, в БД только SHA-256, срок до 30 дней, одноразовые,
  отзываются.
- Панель работает от пользователя `vpnpanel`; `sudo` разрешён только на `/usr/local/sbin/awgctl`.
- База `/var/lib/vpn-panel/panel.db` (600) хранит приватные ключи клиентов, созданных в панели, —
  чтобы конфиг можно было выдать повторно. Бэкапьте её как секрет.
- «Служебные» пиры (например, туннель самого администратора) перечисляются в `protected_pubkeys`
  конфига — панель не даст их отключить или удалить.

| Протокол | Приложения |

| AWG 2.0 | Amnezia VPN 4.8+, AmneziaWG |
| Legacy / WireGuard | Amnezia VPN, AmneziaWG, WireGuard |

## Разработка

```bash
python3 -m unittest discover -s tests -p 'test_*.py'   # панель, без серверов (поддельный awgctl)
sudo tests/smoke-awg3.sh                                 # рукопожатие AWG 3.1 между двумя контейнерами
sudo tests/test-awgctl.sh                                # awgctl против настоящих контейнеров
```
