# vpn-panel

Лёгкая веб-панель для своих VPN-серверов на **AmneziaWG** и установщик **AmneziaWG 3.1** рядом с тем,
что уже стоит (в том числе рядом с контейнерами приложения Amnezia VPN).

- все клиенты со всех серверов в одном окне: кто в сети, когда подключался, откуда, сколько трафика;
- добавить / отключить / включить / переименовать / удалить клиента;
- раздача конфига: **QR прямо с экрана** или **ссылка со сроком** (одноразовая по умолчанию);
- «Перевести на AWG 3.1» — старому клиенту новый конфиг с тем же именем;
- тревога, если сервер не отвечает или VPN-интерфейс в контейнере не поднят — в панели и владельцу в Telegram
  (плюс сертификат < 14 дней, диск < 300 МБ);
- срок действия и лимит трафика у клиента: автоотключение, напоминания в бот, продление одной кнопкой;
- бот выдаёт конфиги по заявкам — только после одобрения владельцем;
- учётки: **владелец** (всё, включая учётки) и **админ** (клиенты только на отмеченных серверах);
  коллеге выдаётся одноразовая ссылка на 48 ч — пароль он задаёт сам; смена пароля в «Профиле»;
- панель — один процесс Python из стандартной библиотеки (+ вложенный `segno` для QR), ~25 МБ памяти,
  без Docker, без базы данных-сервера, без CDN.

Протоколы:
- **AmneziaWG 3.1** — контейнер `awg3` (ставит этот пакет); плюс управление контейнерами приложения Amnezia
  (`amnezia-awg2`, `amnezia-awg` Legacy, `amnezia-wireguard`);
- **VLESS REALITY** — контейнер `xray` (Xray 26.3.27), пользователи добавляются на лету; установщик сам
  проверяет REALITY настоящим клиентом и подбирает рабочий SNI;
- **SSTP** — контейнер `sstp` (accel-ppp 1.14.0) или уже стоящий системный accel-ppp.

Серверы добавляются **из панели** («Серверы» → «Добавить»): SSH-адрес и root-пароль или ключ — один раз, чтобы
положить на сервер `vpnctl` и ключ панели, который умеет только управлять VPN. Протоколы ставятся и удаляются
кнопкой, журнал установки виден на странице. Конфиг клиенту можно отправить **в Telegram** (свой бот панели,
пользователь жмёт Start по ссылке) или **на почту** (SMTP) — «Настройки».

## Установка

**Пошагово, с нуля до выданного VPN: [docs/QUICKSTART.md](docs/QUICKSTART.md).**

Нужны Debian 12 / Ubuntu 22.04+, root, `python3` ≥ 3.9. Для VPN-сервера — Docker (поставится сам).

```bash
git clone https://github.com/igruli0807/vpn-panel /opt/vpn-panel && cd /opt/vpn-panel

# 1. VPN-сервер: AmneziaWG 3.1 в контейнере "awg3" (ключи, обфускация и порт — сами)
./install.sh server --proto awg3          # или sstp / vless (можно и кнопкой из панели)

# 2. Панель (на том же или на другом хосте); контейнеры этого хоста подключатся автоматически
./install.sh panel --id fin --title "Финляндия" --tz Europe/Helsinki
vpn-panel-passwd && systemctl start vpn-panel      # пароль владельца, логин admin (≥ 10 символов)

# 3. Ещё один VPN-сервер в ту же панель (запускать на хосте панели)
./install.sh add-server --id usa --title "США" --host 203.0.113.10

# Домен с настоящим сертификатом, почта, защита SSH, бэкап
./install.sh domain --name vpn.example.com
./install.sh mail --domain example.com
./install.sh harden
./install.sh backup --to 203.0.113.10

# Что работает и чего не хватает
./doctor.sh
```

Панель откроется на `https://<IP>:2053`. Сертификат самоподписанный: браузер один раз предупредит.

Удалить протокол: кнопкой в «Серверах» или `./install.sh server --remove --proto awg3|sstp|vless`
(данные остаются на сервере в стороне).

## Как устроено

```
 браузер ──HTTPS──▶ vpn-panel (python, пользователь vpnpanel)
                       │  sudo awgctl ...            (локальный сервер)
                       │  ssh awgctl ...             (удалённый: ключ с command=, from=, no-pty)
                       ▼
                    awgctl ──docker exec──▶ awg3 / amnezia-awg2 / amnezia-awg / amnezia-wireguard
```

- `server/vpnctl` (бывший `awgctl`, имя оставлено ссылкой) — единственная точка изменений на VPN-сервере:
  драйверы AWG / SSTP / VLESS, `install` / `uninstall` / `preflight` / `unlink`. Правит конфиг атомарно (с копией
  предыдущих 20 версий в `/var/backups/awgctl`), применяет к живому интерфейсу без разрыва сессий,
  для контейнеров Amnezia обновляет `clientsTable`, чтобы приложение видело те же имена. Приватные
  и preshared-ключи наружу не отдаёт никогда. Отключённые клиенты лежат в `<conf>.disabled`.
- `images/awg3` — образ: amneziawg-go и amneziawg-tools 3.1 (userspace, ядро 6.7+ не нужно) и
  сторож: если интерфейс пропал — поднимает снова. Готовый образ: `ghcr.io/igruli0807/awg3`.
- `server/awg-guard.*` — тот же сторож для контейнеров приложения Amnezia: они умеют неделями
  висеть «Up» без VPN-интерфейса после перезагрузки.
- Имя контейнера `awg3`, а не `amnezia-*`: приложение Amnezia его не увидит и не перезапишет.
  Клиенты подключаются к нему импортом конфига/QR, а не через «управление сервером» в приложении.

## Учётки и восстановление доступа

- «Учётки» (только владелец): новая учётка → ссылка-приглашение; «Сбросить пароль» — новая ссылка,
  старый пароль и сеансы гаснут сразу; отключить / удалить; последнего владельца удалить нельзя.
- «Профиль» (у каждого): смена пароля (другие сеансы закрываются), логин и имя, «выйти на всех устройствах».
- Журнал показывает, кто что сделал; админ видит только события своих серверов.
- Забыли пароль — на хосте панели:
  ```bash
  vpn-panel-passwd            # пароль первого владельца (или: vpn-panel-passwd <логин>)
  sudo -u vpnpanel env PYTHONPATH=/opt/vpn-panel/panel:/opt/vpn-panel/panel/vendor \
    VPN_PANEL_CONFIG=/etc/vpn-panel/config.json python3 -m vpnpanel user list|add|invite ...
  ```

## Бэкап

```bash
./install.sh backup --to 203.0.113.10     # на хосте панели: каждую ночь, 7 копий локально + 14 на втором сервере
```
В бэкапе — база панели (ключи клиентов, учётки), `config.json` и SSH-ключи панели; шифрование AES-256, пароль —
`/etc/vpn-panel/backup.pass`. **Сохраните его отдельно**: без него бэкап не расшифровать. На втором сервере ключ
панели умеет только принять файл бэкапа (`vpn-backup-recv`).

Восстановление: `openssl enc -d -aes-256-cbc -pbkdf2 -iter 200000 -pass file:backup.pass -in ФАЙЛ | tar -xz`,
затем `panel.db` → `/var/lib/vpn-panel/`, `config.json` и `ssh/` → `/etc/vpn-panel/`, `systemctl restart vpn-panel`.

## Безопасность

- Вход по логину и паролю (scrypt); 5 ошибок за 15 минут — на час блокируется и IP, и логин.
- Сессии в БД (хранится только хэш токена), cookie `Secure; HttpOnly; SameSite=Strict`, CSRF на всех
  изменениях, CSP `default-src 'self'`, без inline-скриптов и стилей.
- Ссылки для клиентов: 256 бит случайности, в БД только SHA-256, срок до 30 дней, одноразовые,
  отзываются.
- Панель работает от пользователя `vpnpanel`; `sudo` разрешён только на `/usr/local/sbin/awgctl`.
- База `/var/lib/vpn-panel/panel.db` (600) хранит приватные ключи клиентов, созданных в панели, —
  чтобы конфиг можно было выдать повторно. Бэкапьте её как секрет.
- «Служебные» пиры (например, туннель самого администратора) перечисляются в `protected_pubkeys`
  конфига — панель не даст их отключить или удалить.

## Разработка

```bash
python3 -m unittest discover -s tests -p 'test_*.py'   # панель, без серверов (поддельный awgctl)
sudo tests/smoke-awg3.sh                                 # рукопожатие AWG 3.1 между двумя контейнерами
sudo tests/test-awgctl.sh                                # AWG-драйвер против настоящих контейнеров
sudo tests/test-vpnctl.sh                                # SSTP и VLESS: установка + настоящие клиенты sstpc и xray
```
