# Быстрый старт: от чистого VDS до выданного VPN

Нужно: VDS с Debian 12 или Ubuntu 22.04+ (1 vCPU, от 700 МБ RAM, от 2 ГБ свободного диска), root-доступ по SSH.
Домен — желательно (настоящий сертификат, SSTP для Windows без импорта, почта), но не обязательно.

Все команды — от root на сервере панели. Повторный запуск любого шага безопасен.

## 1. Панель

```bash
apt-get update && apt-get install -y git python3 openssl sudo
git clone https://github.com/igruli0807/vpn-panel /opt/vpn-panel && cd /opt/vpn-panel
./install.sh panel --id fin --title "Финляндия" --tz Europe/Moscow
vpn-panel-passwd && systemctl start vpn-panel     # пароль владельца, логин admin
```

Панель: `https://<IP>:2053` (пока с самоподписанным сертификатом — браузер один раз предупредит).

## 2. Протокол на этом же сервере

Из панели: **«Серверы» → «Установить AWG 3.1 / SSTP / VLESS»** (журнал установки виден на странице).
Или командой: `./install.sh server --proto awg3` (или `sstp`, `vless`).

- **AWG 3.1** — лучший вариант для Amnezia VPN 5.0.1.5+ и AmneziaWG 3.1 (UDP, случайный порт).
- **VLESS REALITY** — для v2rayNG / Hiddify / Shadowrocket; установщик сам подбирает рабочий SNI и проверяет себя.
- **SSTP** — встроенный VPN Windows, MikroTik, Android (Open SSTP Client).

## 3. Домен и настоящий сертификат (желательно)

1. У регистратора: A-запись `vpn.example.com` → IP сервера. TCP 80 на сервере должен быть свободен.
2. `./install.sh domain --name vpn.example.com`

Сертификат Let's Encrypt ставится в панель, SSTP и почту и продлевается сам. Ссылки для клиентов
начинают выдаваться с доменом — без предупреждений браузера.

## 4. Ещё серверы

**«Серверы» → «Добавить сервер»**: SSH-адрес и пароль root (или приватный ключ) — один раз. Панель кладёт
на сервер `vpnctl` и свой ключ, который умеет только управлять VPN; пароль нигде не сохраняется.
Затем — «Установить …» на карточке нового сервера.

## 5. Telegram-бот (выдача конфигов и уведомления)

1. В Telegram у @BotFather: `/newbot` → получить токен.
2. **«Настройки» → Telegram**: вставить токен → «Проверить и сохранить».
3. **«Настройки» → «Заявки в мой Telegram»**: открыть ссылку в своём Telegram.

Теперь: люди пишут боту «Запросить доступ» → вам приходит заявка с кнопками «AWG 3.1 · …», «VLESS · …»,
«Отклонить» → после одобрения бот сам присылает человеку настройки. Сюда же приходят тревоги
(сервер не отвечает, VPN не поднят, сертификат, диск). Из карточки любого клиента: «Ссылка на бота».

**Управление из Telegram.** Для привязанной учётки `/start` в боте открывает меню, как в панели: клиенты
(карточка, конфиг себе, ссылка для человека, отключить/включить, +1 месяц, удалить), новый клиент
(сервер·протокол → имя сообщением → QR и файл сразу), заявки, состояние серверов. Админ видит только свои серверы.

## 6. Почта (необязательно)

`./install.sh mail --domain example.com` — отправляющий почтовый сервер (слушает только localhost, DKIM).
Команда напечатает записи DNS (SPF, DKIM, DMARC) — внесите их у DNS-провайдера и попросите хостера поставить
PTR IP-адреса на ваш домен. Проверка: «Настройки» → «Почта» → «Тестовое письмо».

## 7. Безопасность и бэкап

```bash
./install.sh harden                       # ограничение перебора паролей SSH, журналы не распухают
./install.sh backup --to 203.0.113.10     # ночной шифрованный бэкап: 7 копий здесь + 14 на втором сервере
```

**Сохраните `/etc/vpn-panel/backup.pass` отдельно** — без него бэкап не расшифровать.

## 8. Коллеги

**«Учётки» → «Новая учётка»**: роль «админ» + галки серверов → одноразовая ссылка на 48 часов, по которой
коллега сам задаёт пароль. Админ видит и меняет только клиентов своих серверов.

## Каждый день

- **Клиенты** — кто в сети, трафик, «+ Добавить клиента» (можно сразу со сроком и лимитом ГБ в месяц).
- **Карточка клиента** — QR, файл, ссылка со сроком, «Ссылка на бота», почта, «Срок и лимит», отключить/удалить,
  «Перевести на AWG 3.1» для старых клиентов приложения Amnezia.
- **Заявки** — одобрение запросов из бота.
- `./doctor.sh` — что работает и чего не хватает.

## Если что-то сломалось

| Симптом | Что сделать |
|---|---|
| Красная плашка «интерфейс VPN не поднят» | подождать минуту (сторож `awg-guard` поднимет сам), иначе «Серверы» → «Проверить» |
| Забыт пароль панели | `vpn-panel-passwd` на сервере панели |
| Сервер «не отвечает» | `./doctor.sh`; на сервере `vpnctl list`; обновить агент: «Серверы» → «Обновить агент» |
| Нужно восстановить панель | README → «Бэкап» |
