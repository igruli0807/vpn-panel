# VPN-панель — бриф для генерации дизайна

Документ для дизайнера или генератора интерфейсов (v0, Figma AI, Claude и т. п.). Описывает, **что умеет
панель и что есть на каждом экране**. Как это должно выглядеть — решает дизайн; ниже только функция,
данные, состояния и технические рамки.

---

## 1. Что это за продукт

Веб-панель для одного администратора, который держит свои VPN-серверы (сейчас два: «Финляндия» и «США»)
и раздаёт доступ знакомым и коллегам. На каждом сервере работают несколько VPN-«контейнеров» разных
протоколов. Панель собирает их в одно окно:

- видно всех клиентов со всех серверов, кто сейчас в сети, когда подключался, сколько трафика;
- можно добавить клиента, отключить, включить, переименовать, удалить;
- конфиг раздаётся **QR-кодом прямо с экрана** или **ссылкой с ограниченным сроком**, которую клиент
  открывает у себя на телефоне;
- старых клиентов можно одной кнопкой «перевести» на новый протокол AWG 3.1;
- панель предупреждает, если сервер не отвечает или VPN на нём «упал».

Две аудитории:
1. **Администратор** — единственный, кто входит в панель. Технарь, заходит и с ноутбука, и с телефона,
   часто — чтобы быстро выдать доступ человеку, который стоит рядом (показать QR с экрана).
2. **Клиент** — обычный человек, не технарь. Видит только **одну публичную страницу** по ссылке: свой QR,
   кнопку «скачать» и три шага инструкции. Открывает её с телефона.

Язык интерфейса — русский. Тон — спокойный, деловой, без канцелярита и без жаргона на клиентской странице.

## 2. Технические рамки (важно для генерации)

- **Серверный рендеринг HTML**, без React/Vue и без сборки. Разметка — обычные формы (`<form method=post>`),
  ссылки, таблицы. JavaScript — минимальный и необязательный (копирование в буфер, подтверждение
  удаления, автоотправка фильтров). Всё должно работать и без JS.
- **Никаких внешних ресурсов**: ни CDN, ни Google Fonts, ни картинок с других доменов (строгая политика
  CSP `default-src 'self'`). Шрифт — системный стек или один самостоятельно размещённый. Иконки —
  inline SVG.
- **Без inline-стилей** в разметке (CSP запрещает `style=""`) — только классы и один CSS-файл.
- Графики — **inline SVG**, которые рисует сервер (столбики трафика).
- QR-код — готовый SVG от сервера, чёрный на белом, его нельзя перекрашивать и ставить на цветной фон
  (должен сканироваться с экрана с 30–50 см).
- **Светлая и тёмная тема** по системной настройке (`prefers-color-scheme`).
- **Адаптив**: ширины 390 px (телефон) и 1280 px (ноутбук) — основные. Без горизонтальной прокрутки
  страницы; широкая таблица на телефоне превращается в карточки или прячет второстепенные колонки.
- Сертификат у панели самоподписанный: при первом открытии браузер показывает предупреждение — на
  клиентской странице и в подсказках админки это нужно объяснять одной фразой.

## 3. Экраны

### 3.1. Вход (админ)
- Одно поле «Пароль», кнопка «Войти». Логина нет — администратор один.
- Состояния:
  - ошибка «Неверный пароль»;
  - блокировка «Слишком много неудачных попыток. Попробуйте через час.» (после 5 ошибок за 15 минут IP
    блокируется на час) — визуально строже обычной ошибки.
- Маленькая подпись с названием панели; больше ничего на экране нет.

### 3.2. Главная — «Клиенты» (админ)
Верхняя панель навигации: логотип/название «VPN-панель», пункты «Клиенты», «Добавить», «Журнал»,
справа «Выйти». На телефоне — компактное меню.

**Блок тревог** (показывается только при проблеме, над всем остальным, красный):
- «Сервер США не отвечает: timeout» — сервер недоступен;
- «Финляндия / amnezia-awg2: интерфейс VPN не поднят — клиенты не подключатся» — контейнер жив, а VPN нет.
  Это самый важный сигнал панели: однажды такой сбой неделю никто не замечал.

**Карточки контейнеров** — по одной на каждый VPN-контейнер каждого сервера (сейчас 7). В карточке:
- сервер («Финляндия»);
- протокол-бейдж: `AWG 3.1` (новый, рекомендуемый), `AWG 2.0`, `AWG Legacy`, `WireGuard`;
  в будущем добавятся `SSTP` и `VLESS` — бейджи должны быть различимы по цвету/форме;
- порт: «UDP 41000»;
- главное число: «4 в сети из 9»;
- состояние: норма (зелёный акцент) / интерфейс не поднят (красный);
- клик по карточке = фильтр таблицы по этому контейнеру.

**Таблица клиентов** (от 5 до ~100 строк):
- заголовок «Клиенты» и счётчик; кнопка «+ Добавить клиента»;
- фильтры: сервер (выпадающий список), статус (все / в сети / не в сети / отключены / переехали /
  удалённые), поиск по имени или IP, «сбросить»;
- колонки:
  1. индикатор: зелёный — в сети (рукопожатие меньше 3 минут назад), серый — не в сети, красный — отключён;
  2. имя (ссылка на карточку) + метки: «отключён», «переехал», «удалён», «служебный» (служебный — туннель
     самого администратора, его нельзя трогать);
  3. сервер + протокол мелко под ним;
  4. IP внутри VPN (`10.8.3.2/32`, моноширинный);
  5. последнее подключение: «только что», «5 мин назад», «3 дн назад», «никогда» + под ним внешний IP
     клиента мелко (`198.51.100.47:6926`); при наведении — точная дата;
  6. трафик за 24 часа;
  7. трафик за 30 дней;
- сортировка по умолчанию — сначала кто подключался недавно;
- пустое состояние: «Нет клиентов под этот фильтр»;
- подпись под таблицей: «Трафик считается с момента запуска панели. «В сети» — рукопожатие за последние
  3 минуты.»

### 3.3. Новый клиент (админ)
- Поле «Имя» (до 64 символов, пример-плейсхолдер «Иван, телефон»).
- Выбор «Сервер и протокол»: список вида «Финляндия — AWG 3.1 (UDP 41000)», AWG 3.1 первыми.
- Пояснение мелко: «AWG 3.1 — для Amnezia VPN 5.0.1.5+ и AmneziaWG 3.1. AWG 2.0 — для тех, у кого
  приложение старое.»
- Кнопка «Создать» → сразу открывается карточка клиента с QR (главный сценарий: создал и тут же показал
  QR человеку рядом).
- Ошибка создания показывается над формой.

### 3.4. Карточка клиента (админ) — главный рабочий экран
**Шапка**: имя клиента, ссылка «← все клиенты». Если клиент переехал — «Переехал: новый клиент» со ссылкой.

**Сведения** (список «название — значение»):
сервер и протокол · IP в VPN · статус (в сети / не в сети / отключён / удалён) · последнее подключение
(дата и «N назад») · откуда (внешний IP:порт) · трафик: 24 ч / 30 дн / всего · создан (дата, «в панели»
или «в приложении Amnezia»).

**График трафика за 7 дней**: 28 столбиков по 6 часов, подсказка с датой и объёмом на каждом;
подпись «максимум 1.2 ГБ». Пустое состояние: «Трафика за неделю нет».

**Действия**:
- переименовать (поле + кнопка);
- отключить / включить (переключаемое состояние; отключённый клиент хранится, но не подключается);
- «Перевести на AWG 3.1» (только для старых протоколов: выбор целевого сервера + кнопка) — создаёт
  нового клиента с тем же именем и открывает его карточку;
- удалить — опасное действие, с подтверждением «Удалить клиента «Иван»? Его VPN перестанет работать.»;
- для служебного пира вместо кнопок — пояснение «Служебный пир — изменения из панели запрещены».

**Блок «Конфиг»** (есть только у клиентов, созданных в панели):
- **большой QR-код** — центральный элемент экрана, должен удобно сканироваться с экрана ноутбука
  и с экрана телефона администратора;
- подпись, в каком приложении сканировать (зависит от протокола);
- кнопки «Скачать .conf» и «Копировать текст».
- У клиентов, импортированных из приложения Amnezia, ключа нет — вместо блока пояснение: «Выдайте ему
  новый конфиг через «Перевести на AWG 3.1»».

**Блок «Ссылка для клиента»**:
- срок: 24 часа / 3 дня / неделя; галка «одноразовая» (по умолчанию включена); кнопка «Создать ссылку»;
- после создания — заметная плашка с полем-ссылкой и кнопкой «Копировать»; «Показана один раз»;
- подсказка про предупреждение браузера о сертификате;
- таблица выданных ссылок: создана · действует до · тип · состояние (не открывалась / использована
  <дата> / истекла / отозвана) · «отозвать».

### 3.5. Публичная страница клиента (по ссылке, без входа)
Открывает обычный человек на телефоне. Максимально просто и дружелюбно:
- заголовок «Ваш VPN», «Подключение для: Иван, телефон»;
- три шага: 1) установите приложение (название зависит от протокола, например «Amnezia VPN 5.0.1.5+»);
  2) в приложении «+» → «QR-код» или «Файл»; 3) включите подключение;
- QR-код;
- главная кнопка «Скачать файл конфигурации», второстепенная «Копировать текст»;
- предупреждение мелко: «Это ваш личный ключ — не пересылайте его. Ссылка может быть одноразовой:
  сохраните файл сейчас.»
- Нет навигации админки, нет упоминаний серверов и IP.
- Состояния: «Ссылка недействительна: истекла, уже использована или отозвана» и «Сервер временно
  недоступен, попробуйте позже».

### 3.6. Журнал (админ)
Таблица последних 300 событий: когда · IP · что («вход в панель», «создан клиент «Иван» (fin/awg3)»,
«отключён клиент «Мария»», «ссылка для «Иван»», «открыта ссылка клиента «Иван»»). Простая, плотная.

### 3.7. Служебные состояния
- 404 «Нет такой страницы», 500 «Внутренняя ошибка панели», 403 «Форма устарела, обновите страницу».
- Уведомления после действий (успех/ошибка) — плашка вверху карточки.

## 4. Компоненты, которые понадобятся

Верхняя навигация · плашки тревоги/успеха · карточка-статистика контейнера · бейдж протокола (6 видов:
AWG 3.1, AWG 2.0, AWG Legacy, WireGuard, SSTP, VLESS) · индикатор статуса (3 цвета + подпись для
доступности) · метки-теги · таблица с адаптивом · фильтры · поля и выпадающие списки · кнопки: основная,
второстепенная, опасная, текстовая · список «название — значение» · SVG-график столбиками · блок QR ·
поле-ссылка с кнопкой «Копировать» · пошаговая инструкция · пустые состояния.

## 6. Что ждём от дизайна

1. Экраны: вход, главная, новый клиент, карточка клиента (с QR и выданными ссылками), публичная страница
   клиента, журнал, страница «ссылка недействительна».
2. Каждый экран — в двух ширинах (390 и 1280) и двух темах (светлая, тёмная).
3. Отдельно — главная в состоянии тревоги (сервер не отвечает + интерфейс не поднят).
4. Набор токенов: цвета (фон, поверхность, текст, приглушённый текст, линии, акцент, успех, тревога,
   цвета шести бейджей протоколов), радиусы, отступы, размеры шрифта — чтобы перенести в один CSS-файл.
5. Характер: инструмент администратора — плотный, спокойный, читаемый; клиентская страница — мягче
   и крупнее, «для мамы».
